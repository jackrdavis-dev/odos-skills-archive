# Release content contract

Create these files in the release staging directory:

- `public-announcement.md`
- `patreon-basic.md`
- `patreon-deluxe.md`
- `patreon-premium.md`
- `shop-listing.md`
- `verification-plan.md`

## Source authority

Use `release-context.json`, `cover.png`, `overview.png`, and the embedded tier manifests. Do not infer unsupported story facts. If level, party size, runtime, tone, or premise cannot be read confidently, omit it or stop for source clarification.

## Public announcement

Use the title `New Adventure: <Title> | One Dollar One Shots`. Write 150-250 spoiler-light words covering the hook, table experience, usable format, and three editions. End with a clear Patreon/shop call to action. Use the cover as hero art and provide one-sentence alt text. Include clearly labeled links for `Basic Download`, `Deluxe Download`, `Premium Download`, and `Buy in the DiceStory Shop`; replace every placeholder with the authoritative live URL before publishing. Enable email and push notifications for this announcement, which is the release's only notified post.

## Fulfillment posts

Use titles `<Title> — Basic Download`, `<Title> — Deluxe Download`, and `<Title> — Premium Download`. Write 50-120 words each. State the exact edition, summarize included assets from the manifest, name the attached ZIP, and explain the next edition's added value without overstating it.

Disable email and push notifications on all three fulfillment posts. Their audience restrictions and attached ZIPs remain the source of truth for access; the announcement links to these posts but never embeds their files.

## Shop listing

Include:

- Product title and spoiler-light short description.
- Full marketing description.
- Verifiable adventure facts.
- A Basic/Deluxe/Premium comparison derived from manifest role counts.
- Exact prices and delivery filenames.
- A concise license/download note only when the shop supplies an approved policy.
- SEO title and meta description.
- An image plan naming the cover source, alt text, card mode/crop, and detail-page mode/width.

Use `Starting at $1` where a single summary price is required.

## Style

Write energetic, practical Game Master-facing copy. Emphasize fast preparation, playability, maps, tokens, handouts, and appendix material when present. Avoid generic superlatives, fake testimonials, rules claims not visible in the packet, and spoilers about hidden villains or solutions.
