# ODOSv5 Text Budgets

## General

- Prefer short bullets over paragraphs.
- Preserve names, numbers, and mechanics.
- Do not preserve every source paragraph.
- If a page is too dense, split content between core and appendix.
- Never shrink important table-use text until it is unreadable.

## Read-aloud minimums

- overview opening read-aloud: 75-120 words
- scene read-aloud: 55-90 words
- finale read-aloud: 75-120 words

Read-aloud must include sensory detail, immediate stakes, and one actionable visual cue.

## Dialogue minimums

NPC dialogue should include:
1. hook / information line
2. emotional / personality line
3. pressure / escalation line

Villain dialogue should include:
1. opening threat
2. bargain / taunt
3. midfight escalation
4. defeat / retreat line

Each line should be 8-18 words.
Avoid generic one-liners unless the NPC is intentionally terse.

## Core page budgets

### Page 1 Overview
- pitch: 45-70 words
- opening read-aloud: 75-120 words
- starting hook: 3-5 bullets
- at a glance: 5-6 short bullets
- DM tip: 20-35 words

### Page 2 NPCs
Per NPC:
- roleplay summary: 15-30 words
- reveal/help summary: 25-45 words
- dialogue: 3 lines, 8-18 words each
- compact stat block: 6-10 lines

### Page 3 Monsters / Villain
- villain roleplay: 35-60 words
- villain dialogue: 4 lines, 8-18 words each
- villain compact stats: 8-12 lines
- minion stat cards: 6-10 lines each
- tactics box: 4-6 bullets

### Page 5 Scene 1
- read-aloud: 55-90 words
- what they see: 5-8 bullets
- key checks: 4-6 checks
- clues: 3-5 bullets
- secrets: 1-3 bullets
- trap/puzzle/hazard/combat: 4-8 bullets
- point forward: 20-35 words
- fail forward: 20-35 words

### Page 7 Finale
- read-aloud: 75-120 words
- combat environment: 5-8 bullets
- key checks: 4-6 checks
- win/fail conditions: 4-8 bullets
- escalation: 3-5 stages
