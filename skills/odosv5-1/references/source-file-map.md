# ODOSv5 Source File Map

Use this map to read ODOS Studio / Packet Foundry exports.

## `project.json`

Use for manifest, title, selected option, generated sections, metadata, adventure ID, and generator output context.

## `selected_concept.md`

Use for adventure title, premise, one-sentence pitch, tone, core fantasy, villain concept, and why the adventure matters.

## `adventure_skeleton.md`

Use for scene list, pacing, adventure structure, core beats, and escalation concept. Do not let an old skeleton page plan override ODOSv5 page contracts.

## `dm_packet.md`

Use for hooks, adventure overview, scene details, read-aloud text, locations, rewards, finale, and running notes.

## `npc_suite.md`

Use for NPC names, roles, roleplay notes, motives, secrets, dialogue, NPC stat blocks, and portrait/token notes.

## `stat_blocks.md`

Use for monsters, main villain, combat stat blocks, hazards, traps, scaling, and tactics.

## `clue_web.md`

Use for required clues, optional clues, fail-forward clues, secrets, clue placement, if players stall guidance, minor scene suggestions, and DM troubleshooting.

## `visual_asset_brief.md`

Use for subject inventory, asset roster, token needs, battlemap needs, location facts, prop facts, and adventure-specific visual facts only. Do not use this file for final art style. ODOSv5 style rules, `art-style-samples/`, and the visual-noise ban override all style wording.

## `art_prompts.md` legacy input

Treat only as a legacy asset inventory. Strip or ignore style, medium, rendering, lighting, palette, texture, and image-model wording. Keep only subjects, names, locations, props, token needs, battlemap needs, and asset checklist items.

## `codex_handoff.md`

Use only if it has ODOSv5-compatible instructions. If it refers to an older page structure, ignore conflicting sections and follow ODOSv5.
