# ODOSv5 Page Contracts

Every generated core page must satisfy its page contract. If a page cannot satisfy its contract, regenerate or report failure.

## Page 00: Cover Page

Must include:
- ODOS packet identity / logo treatment
- adventure title
- level range
- one-sentence hook
- 3 teaser medallions
- large cinematic cover illustration
- footer branding ribbons

Hard fail:
- missing adventure title
- no ODOS-style identity
- gritty/noisy art
- worksheet-style page
- obvious gibberish in major visible text

## Page 01: Adventure Overview

Must include:
- title
- pitch
- recommended level / party size
- runtime
- tone
- clear adventure engine: what the party repeatedly chooses, risks, spends, or protects
- stakes and failure pressure in table-ready terms
- opening read-aloud
- starting hook
- why it matters
- properly labeled `AT A GLANCE` panel
- DM tip

AT A GLANCE must include at least 5 useful icon bullets:
- genre / mood
- recommended level and party size
- runtime
- core mystery or problem
- primary challenge types
- finale pressure / choice

Adventure overview explanation must answer:
- What is the adventure about in one sentence?
- What do the characters do again and again during play?
- What gets worse if they delay or fail?
- What choices meaningfully change later scenes?
- What should the DM track from the first scene onward?

Read-aloud:
75-120 words unless source material is extremely short.

Hard fail:
- missing At a Glance panel
- no read-aloud
- read-aloud under 50 words
- no starting hook
- no pitch

## Page 02: NPCs

Must include:
- 3 primary NPCs
- portrait for each NPC
- role / function
- how to roleplay each NPC
- what they reveal or how they help
- 3 dialogue suggestions for each NPC
- compact D&D-usable stat sheet for each NPC
- sidebar explaining how to use the NPCs
- Innkeeper's Tip
- page number 2

Stat cards:
Use compact D&D-style stat blocks, not icon-only tiles.

Hard fail:
- stats are only icons
- missing AC, HP, Speed, or ability scores
- fewer than 3 dialogue lines per NPC
- dialogue is generic or only 1-3 words
- art does not match clean cartoon fantasy

## Page 03: Monsters / Main Villain

Must include:
- main villain profile
- how to roleplay the main villain
- villain motives and pressure
- villain dialogue options
- combat behavior / tactics
- compact stat sheet for the main villain
- 2-3 monster or minion stat cards
- scaling notes
- combat / dialogue options

Hard fail:
- lacks usable actions
- missing AC / HP / Speed
- missing villain roleplay or dialogue
- icon-only monster stats
- no combat tactics

## Page 04: Scene Flow Overview

Must include:
- brief at-a-glance info for every major scene
- purpose of each scene
- location
- primary challenge
- important reveal or clue
- point forward
- escalation / adventure clock
- visual route, path, flowchart, or scene ladder
- page number 4

Scene Flow Direction Rule:
If the adventure involves ascent, descent, travel, chase, or pursuit, the visual path must match numbered scene order.
Scene 1 must appear at the start of the path.
The finale must appear at the end of the path.
For mountain ascent, Scene 1 begins at the bottom / lower trail and the finale appears at the summit / top.
Do not place Scene 1 at the top of the mountain.
Do not reverse the visual arrows relative to the numbered cards.
Every arrow must point from lower scene number to higher scene number.

Hard fail:
- arrows contradict scene numbers
- start/end of physical path is reversed
- no escalation clock
- scenes are missing or out of order

## Page 05: Scene 1

Must include:
- scene title
- setting image
- purpose
- what the characters see
- read-aloud
- key checks
- clues
- secrets
- point forward
- fail forward
- Innkeeper's Tip
- Monster's Mischief if applicable
- trap, puzzle, hazard, or combat details and checks
- handouts to use
- escalation mechanic
- page number 5

Scene page layout:
- setting image should use 30-38% of the page, not half the page
- lower 60-65% should be DM-facing mechanics and scene-running text
- include at least 8 named content boxes

Hard fail:
- scene art takes over the page at the expense of mechanics
- missing read-aloud
- missing key checks
- missing fail-forward
- missing escalation
- no trap/puzzle/hazard/combat box when the source scene includes one

## Page 06: Scenes 2 and 3

Must include for each scene:
- scene title
- purpose
- what the characters see
- read-aloud or compressed read-aloud
- key checks
- clues
- secrets
- point forward
- fail forward
- applicable trap/puzzle/hazard/combat details
- handouts
- escalation mechanic

Also include shared clue trail or escalation tracker, Innkeeper's Tip, Monster's Mischief if applicable, and page number 6.

Hard fail:
- one of the two scenes is missing
- no key checks
- no point forward / fail forward
- read-aloud missing for both scenes

## Page 07: Finale Scene

Must include:
- finale scene title
- what the characters see
- read-aloud
- setting image
- key checks
- clues
- secrets
- point forward and fail forward
- Innkeeper's Tip
- Monster's Mischief if applicable
- trap or puzzle details and checks
- handouts to use
- final combat environment
- how to run combat suggestions
- escalation mechanic
- win / fail conditions
- page number 7

Hard fail:
- no combat environment advice
- no read-aloud
- no win/fail outcomes
- missing escalation

## Page 08: Clues, Secrets, and DM Tools

Must include:
- required clues
- optional clues / secrets
- fail-forward clues
- additional challenges
- minor scene suggestions
- dialogue options
- general useful DM tips and tricks
- if players stall guidance
- page number 8

Hard fail:
- no fail-forward tools
- no dialogue options
- no minor scene / challenge suggestions
- no clue structure

## Page 09: Rewards, Carry Forward, and Continuing

Must include:
- treasure
- consumables
- story rewards
- carry-forward consequences
- how to keep this going if the group wants to play more next week
- loose threads
- future adventure hooks
- what changes if clean success / partial success / failure
- page number 9

Hard fail:
- no next-week suggestions
- no carry-forward hooks
- no treasure/reward section

## Appendix Scene Art Page

Must include full-page scene / setting artwork, small scene title plaque, short mood caption, optional tiny DM use note, and no dense text.

## Appendix NPC Page

Must include full-page NPC art, name and role, full D&D-style stat block, roleplay notes, motives, secrets, 3-5 dialogue lines, and token reference pose if possible.

## Appendix Monster / Villain Page

Must include full monster or villain art, full D&D-style stat block, combat tactics, roleplay / behavior, dialogue if intelligent, and scaling notes.
