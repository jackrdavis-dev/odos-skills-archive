# Character Style Reference Contract

Store only explicitly approved character-rendering references here. They control contour weight, anatomy simplification, facial expression, cel-shading steps, and clean material treatment. They never control production character identity.

Do not add generated reusable references without explicit user approval. Project cast identity belongs in `cast-lock.json`, not here.

Project-specific approved cast sheets and crops in `cast-lock.json` override reusable subjects.
