# Art Style Samples

These current files are the reusable illustration-style authority. Inspect all of them before Gate 1, use them to generate the three calibration proofs, and record their SHA-256 hashes in `style-lock.json`. Approved project proofs translate this reference art into character, environment, token, and map behavior; they do not replace or override it.

These images control:
- character art
- monster art
- scene illustrations
- appendix artwork
- VTT token style
- battle map illustration style

Target style for ODOSv5:
clean cartoon fantasy, bold outlines, smooth cel shading, controlled gradients, expressive characters, clear silhouettes, no speckling, no stippling, no grain, no dimpled texture, no random dots.
